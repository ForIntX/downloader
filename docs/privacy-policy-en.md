# Downloader Privacy Policy

[English](privacy-policy-en.md) | [Türkçe](privacy-policy-tr.md)

Last updated: August 8, 2026

Downloader does not create user accounts, use advertising identifiers, or send
analytics or download history to the developer. URLs, queue data, preferences,
and error logs remain on the user's device.

The application connects to the relevant media service and its network
endpoints only to retrieve requested media information and download files. On
Android, completed files are stored under `Download/video_indirici/musics` or
`Download/video_indirici/videos`.

The first Android release does not sign in to Google accounts or collect
cookies. On Windows, users may choose a local browser profile or `cookies.txt`
file for yt-dlp operations. The application does not read, copy, or log cookie
contents; only the selected method and file path are stored on the device.
Users can remove application data through Android settings or clear the queue
and history with **Clear personal data** inside the application.
