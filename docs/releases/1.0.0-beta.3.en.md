# Downloader 1.0.0 Beta 3

English is now the default language for new installations on Linux, Android,
and Windows. Existing users keep their saved language choice.

## Ready-to-use downloads

- `Downloader-1.0.0-beta.3-Android.apk`: install directly on Android 8 or newer
- `Downloader-1.0.0-beta.3-Windows-Setup.exe`: guided Windows installer
- `Downloader-1.0.0-beta.3-Windows.zip`: portable Windows application
- `Downloader-1.0.0-beta.3-Linux.deb`: double-click installation on Debian/Ubuntu
- `Downloader-1.0.0-beta.3-Linux.tar.gz`: installer for other supported Linux distributions
- `Downloader-1.0.0-beta.3-Android.aab`: Google Play Console package

The Windows installer packaging issue from Beta 2 has been fixed. This is a
beta release. Only download content you are authorized to save.
