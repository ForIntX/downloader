# Downloader 1.0.0 Beta 3

Linux, Android ve Windows'ta yeni kurulumların varsayılan dili artık
İngilizcedir. Mevcut kullanıcıların kayıtlı dil tercihi korunur.

## Kullanıma hazır indirmeler

- `Downloader-1.0.0-beta.3-Android.apk`: Android 8 ve sonrasına doğrudan kurulum
- `Downloader-1.0.0-beta.3-Windows-Setup.exe`: yönlendirmeli Windows kurulumu
- `Downloader-1.0.0-beta.3-Windows.zip`: taşınabilir Windows uygulaması
- `Downloader-1.0.0-beta.3-Linux.deb`: Debian/Ubuntu'da çift tıklayarak kurulum
- `Downloader-1.0.0-beta.3-Linux.tar.gz`: desteklenen diğer Linux dağıtımları için kurucu
- `Downloader-1.0.0-beta.3-Android.aab`: Google Play Console paketi

Beta 2'deki Windows kurulum paketi sorunu düzeltildi. Bu bir beta sürümdür.
Yalnızca indirme izniniz olan içerikleri kullanın.
