# Downloader 1.0.0 Beta 2

This release adds Turkish and English interface support to the Linux, Android,
and Windows applications. The language choice is saved in Settings; Android
download notifications and the Windows installer also support both languages.

## Download files

- `Downloader-1.0.0-beta.2-Android.apk`: direct installation on Android 8 and newer
- `Downloader-1.0.0-beta.2-Android.aab`: Google Play Console package
- `Downloader-1.0.0-beta.2-Windows.zip`: portable Windows application
- `Downloader-1.0.0-beta.2-Setup.exe`: Windows setup wizard
- `Downloader-1.0.0-beta.2-Linux.tar.gz`: Linux application and installer scripts

This is a beta release. Download only content you are authorized to download
from YouTube and other services.
