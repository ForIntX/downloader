# Security policy

[English](SECURITY.en.md) | [Türkçe](SECURITY.md)

## Supported versions

Security fixes are prepared only for the latest beta or stable release.

## Reporting a vulnerability

Do not disclose security vulnerabilities in a public issue. Contact the project
owner through [muhammetburakakkas.com](https://muhammetburakakkas.com). Include
reproduction steps, but do not send real cookies, passwords, account data, or
other personal information.
